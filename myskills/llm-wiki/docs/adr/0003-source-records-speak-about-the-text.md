# A source record speaks about the text, never about the world

The source record holds the `§ map`, the chain, the candidates, the refusals and the glossary — statements about what the text says and where. Verbatim quotes live on the promoted page whose claim they support, cited back by anchor; the record itself carries `quotes_check: 0`. This is what lets the record be *mutated* on every sweep (a candidate's status changes) without ever touching evidence, and lets it be published while the claims it feeds are still undecided.

Recorded now because it was decided in the earlier vault-wide refactor without an ADR, and it is the reason ADR-0002's slot can live inside a record that holds no claims. Rejected: quoting in the record, which gives every quote two homes and silently orphans the page relying on it when the quote moves.
