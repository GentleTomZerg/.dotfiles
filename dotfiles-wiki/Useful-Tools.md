# Monitors
- `Arandr`
It is tedious to use `xrandr` to switch between screens. `Arandr` has a GUI interface and saves time.
- `autorandr` command line tool to change monitor.

# Grub
- [grub-tools](https://www.youtube.com/watch?v=VaIgbTOvAd0)
tells you how to config grub to dual boot Fedora and Windows.

# Fonts
- [getnf](https://github.com/ronniedroid/getnf)
use command `getnf` in terminal to download nerd-fonts easily.
- The other good way is to download the font packages and uzip them. Copy the output to ~/.local/share/fonts/
