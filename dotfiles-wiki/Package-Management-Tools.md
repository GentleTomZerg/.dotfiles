# `dnf`
`dnf` is the built-in package management tool of Fedora.

# `rpm` && `flatpak`
`dnf` didn't provide enough packages for Fedora. So we need other managers to help. Normally, we need to add `rpm` and `flatpak` to help us. This [7 things you need to do after install Fedora](https://www.youtube.com/watch?v=RrRpXs2pkzg) is very helpful.

[rpm](https://rpmfusion.org/Configuration)
[flatpak](https://flatpak.org/setup/Fedora)

# `snapd`(not recommended)
It is still not enough, we I want to use a markdown render called `glow`, it is hard to download it through the three managers above. Since `glow` is experimental and not stable enough to release. So, `snapd` is another tool we need to install. This [link](https://snapcraft.io/install/glow/fedora) shows you how to get `snapd` on your Fedora.
